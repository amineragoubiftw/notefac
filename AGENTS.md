# Architecture
- Keep the hosted TanStack Start app unchanged; desktop packaging uses a separate Vite client entry with the same calculator view and TanStack Router so no server runtime is needed for offline calculations.
- Run Electron with isolated, sandboxed renderers and no Node integration; store local grades in its persistent application profile and keep cloud sharing online-only.
- Keep the desktop download notice in a browser-only presentation component, suppressed in desktop builds, so installed users are not prompted to install again.
- Keep Custom Mode in an independent web-only workspace with stable IDs for grades; the desktop route tree contains only the calculator, excluding Custom and Admin, so installed users cannot edit or moderate curricula.
- Desktop curriculum refreshes use the public published catalog feed plus approved community proposals, with validated local caches and periodic/reconnect checks; catalog updates never touch personal grade storage so calculations remain available offline.
- Pass optional per-module weights through the existing grading helpers so custom and official calculators share UE weighting, semester weighting, and credit validation semantics.- Community curriculum additions are stored as moderated proposals and merged into the static official catalog at runtime (useCurriculum); approved additions only append and never overwrite official modules, so the bundled data stays the source of truth and works offline via cache.
